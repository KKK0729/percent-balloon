# 🎈 PERCENT BALLOON（パーセントバルーン）

テレビ番組風の演出で楽しめる、ブラウザ完結型の「パーセントバルーン」Webアプリケーションです。
**投影用画面（メインモニター）** と **司会者用コントローラー（別ウィンドウのポップアップ）** を分けて2画面で進行できます。

## ✨ 主な機能
- **🪟 投影用画面と操作用ポップアップの2画面分離**:
  - ゲーム開始時（またはワンクリック）で **「司会者コントローラー (`controller.html`)」** が別ウィンドウで開き、投影用画面からは操作パネルが完全に消えます。
  - プロジェクターやZoom/Teamsのウィンドウ共有にはメイン画面だけを映し、手元のコントローラー画面で回答入力や正解発表を行えます。
- **📂 CSVファイル / 問題セットの自動読み込み**:
  - `問題文, 正解数値` の2列で作ったCSVファイル（Excel等で作成可能・UTF-8 / Shift-JIS両対応）を開始画面で選択すると、問題数・各問の問題文・正解が自動でセットされます。
  - 司会者コントローラーには「設定されている正解（カンペ）」と「全問題リスト（クリックで問題ジャンプ可）」が表示されますが、投影用画面では「正解を発表！」を押すまで秘密にされます。
  - ファイルを選択しない場合は、従来どおり問題数を指定して自由に入力する手動モード、または内蔵のサンプル問題セット（2種類）でも遊べます。
- **📺 見やすい大型テレビ番組風テロップ**:
  - 投影用画面の上部中央に、ゴールド枠＆視認性の高い大型フォントで問題文と回答者名が大きく表示されます。
- **💥 豪華演出 & Web Audio API 効果音**:
  - ドラムロール演出、誤差分の風船連続破裂、ピタリ賞（誤差0%）の「PERFECT!!」カットイン＆ボーナス風船追加、全問突破時の「GAME CLEAR!!」、風船0個時の「GAME OVER...」ゴンドラ落下演出を搭載。
  - 誤操作しても1つ前の状態に戻せる **「↩ やり直し (Undo)」** 機能付き。

## 📁 ファイル構成
- `index.html` : 投影用メイン画面
- `controller.html` : 別ウィンドウで開く司会者専用コントローラー画面
- `style.css` : スタイルシート
- `app.js` : ゲーム進行・CSV読み込み・2画面同期ロジック
- `balloon-engine.js` : 風船・ゴンドラ物理アニメーションエンジン
- `sound-engine.js` : Web Audio API 効果音エンジン
- `sample-questions.csv` : 問題作成用のサンプルCSVファイル
