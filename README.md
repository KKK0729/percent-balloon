# 🎈 PERCENT BALLOON（パーセントバルーン）

テレビ番組風の演出で楽しめる、ブラウザ完結型の「パーセントバルーン」Webアプリケーションです。

## ✨ 主な機能
- **初期設定カスタマイズ**: 問題数・初期バルーン数（デフォルト100個）・ピタリ賞ボーナス数を自由に設定可能
- **3ステップ進行**:
  1. **回答を表示**: 回答者の予想（0〜100%）をフリップ表示
  2. **正解を発表**: ドラムロール演出とともに正解数値を発表＆誤差を計算
  3. **バルーン計測**: 誤差の数だけ風船が連続破裂！
- **豪華演出 & 効果音**:
  - Web Audio API による効果音合成（外部音声ファイル不要）
  - ピタリ賞（誤差0%）の「PERFECT!!」カットイン＆ボーナス風船追加
  - 全問突破時の「GAME CLEAR!!」紙吹雪演出、風船0個時の「GAME OVER...」ゴンドラ落下演出
- **司会・配信向けサポート機能**:
  - `🙈 正解を隠して入力`: 画面共有中でも正解入力欄を伏せ字（`•••`）にマスク可能
  - `↩ やり直し (Undo)`: 誤入力しても1つ前の状態にワンクリックで復元
  - `🔽 パネルを隠す`（ショートカット: `H` キー）: 操作パネルを最小化してモニター表示に特化

## 🚀 遊び方
ブラウザで `index.html`（または GitHub Pages の公開URL）を開くだけでそのまま遊べます。
